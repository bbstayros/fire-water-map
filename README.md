# fire-water-map

Χάρτης δεξαμενών, πυροσβεστικών κρουνών και σημείων υδροληψίας για τον:

**Σύλλογο Εθελοντών Πυροπροστασίας Δασών Λουτρακίου - Περαχώρας**

## Τρέχουσα έκδοση

Η παρούσα έκδοση περιλαμβάνει:

- δημόσιο διαδραστικό χάρτη,
- τρεις κατηγορίες σημείων,
- διαφορετικά SVG εικονίδια,
- GPS συσκευής,
- πλοήγηση μέσω Google Maps,
- υπόμνημα που λειτουργεί και ως φίλτρο,
- κουμπί «Όλα τα σημεία» που επαναφέρει όλες τις κατηγορίες,
- εμφάνιση κοντινών σημείων σε ακτίνα 10 km όταν χρησιμοποιείται το «Η θέση μου»,
- φόρμα προεπισκόπησης νέου σημείου χωρίς αποθήκευση.

Η πραγματική αποθήκευση, η έγκριση με κωδικό, η επεξεργασία και η διαγραφή
θα προστεθούν στο επόμενο στάδιο.


## Επιλογή ακτίνας

Ο χρήστης επιλέγει άμεσα ακτίνα **2, 4, 6 ή 10 km** με μεγάλα πλήκτρα.
Η προεπιλογή είναι **4 km**. Αν η θέση έχει ήδη εντοπιστεί, η αλλαγή
εφαρμόζεται αμέσως χωρίς νέο πάτημα στο GPS. Εμφανίζεται επίσης κύκλος
στον χάρτη που δείχνει την περιοχή αναζήτησης.
