# fire-water-map

Χάρτης δεξαμενών, πυροσβεστικών κρουνών και σημείων υδροληψίας για τον:

**Σύλλογο Εθελοντών Πυροπροστασίας Δασών Λουτρακίου - Περαχώρας**

## Τρέχουσα έκδοση

Η παρούσα έκδοση περιλαμβάνει:

- δημόσιο διαδραστικό χάρτη,
- τρεις κατηγορίες σημείων,
- διαφορετικά SVG εικονίδια,
- GPS συσκευής,
- πλοήγηση μέσω Google Maps,
- φόρμα προεπισκόπησης νέου σημείου.

Η πραγματική αποθήκευση, η έγκριση με κωδικό, η επεξεργασία και η διαγραφή
θα συνδεθούν σε ασφαλές backend στο επόμενο στάδιο.
